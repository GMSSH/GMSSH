## 什么是极目 Linux 桌面？

极目 Linux 桌面是一款基于 SSH 的 Linux 服务器桌面管理工具。

它无需在服务器上安装完整的桌面环境，也不要求部署额外的管理面板。用户只需通过 SSH 连接服务器，就能像使用 Windows 一样，在桌面化界面中管理文件、使用终端、访问浏览器、运行应用，并借助 GMAI 完成服务器运维任务。

极目 Linux 桌面位于原生 SSH、传统服务器面板和企业级堡垒机之间：

- **原生 SSH** 提供可靠、轻量的远程连接和命令行能力；
- **传统服务器面板** 提供网站、数据库和运行环境等可视化管理能力，但通常需要在服务器上安装并长期运行面板服务；
- **企业级堡垒机** 侧重集中式访问控制、权限管理、操作审计和合规治理，部署与维护成本较高；
- **极目 Linux 桌面** 基于现有 SSH 能力，为个人开发者和小型团队提供更轻量、更直观的服务器访问与操作体验。

极目 Linux 桌面的核心目标是：

> **无需安装桌面环境，也能像使用 Windows 一样管理 Linux 服务器。**

## 为什么需要极目 Linux 桌面？

当服务器从一台增加到多台，问题往往不再是“能不能通过 SSH 连接”，而是如何更高效地组织、切换和使用这些服务器。

个人开发者和小型团队通常会遇到以下情况：

- SSH 地址、端口、账号和密钥分散在终端、脚本和文档中；
- 服务器数量增加后，连接切换、分组管理和环境区分变得混乱；
- 团队成员共享主机信息不方便，也难以控制访问范围；
- 传统服务器面板擅长网站、数据库和运行环境管理，却不适合作为统一的 SSH 连接入口；
- 企业级堡垒机功能完整，但部署、学习和维护成本往往超出个人和小团队的实际需求。

极目 Linux 桌面希望填补原生 SSH 与重型运维系统之间的空白：

> **保留 SSH 的轻量与安全，提供更清晰的多服务器管理和更直观的桌面化操作体验。**
它让用户无需在每台服务器上安装完整桌面环境或额外管理面板，就能从一个客户端连接、切换和管理多台 Linux 服务器。

## 极目 Linux 桌面的产品定位

极目 Linux 桌面可以理解为：

- **统一的 Linux 服务器访问入口**
- **以 SSH 为核心的多主机管理工具**
- **面向个人开发者和中小团队的轻量运维工作台**

它不追求接管服务器上的所有运维工作，而是专注于解决服务器访问和日常操作中的高频问题：

- 让连接信息更有组织；
- 让主机切换更高效；
- 让服务器操作更直观；
- 让远程运维入口更轻量；
- 为团队共享和协作提供基础支持。

## 为什么选择极目 Linux 桌面？

### 1. 更适合多服务器管理

当服务器从几台增加到几十台甚至上百台时，真正影响效率的往往不是能否连接服务器，而是能否清晰地组织、切换和管理它们。

极目 Linux 桌面支持统一管理多台服务器，并通过分组、标签和桌面入口帮助用户区分不同项目、环境和主机。

### 2. 比传统面板更轻量

极目 Linux 桌面不采用“大而全”的服务器面板模式，也不试图替代所有运维工具，而是聚焦于 SSH 连接和服务器日常操作。

它无需在每台服务器上安装完整的桌面环境，也不要求额外部署长期运行的管理面板。通过 SSH 连接并按需使用相关能力，减少服务器侵入和资源占用。

### 3. 比原生 SSH 更清晰

原生 SSH 稳定、可靠且足够轻量，但当服务器、账号、密钥和运行环境不断增加后，连接信息容易分散在终端配置、脚本和文档中。

极目 Linux 桌面保留 SSH 的连接方式，同时提供更清晰的主机管理、分组、连接入口和桌面化操作体验。

### 4. 比重型堡垒机更容易落地

企业级堡垒机适合复杂的权限、审计和合规场景，但部署、学习和维护成本较高。

极目 Linux 桌面提供更低的使用和部署门槛，更适合个人开发者、小型团队和正在成长中的组织。

### 5. 可私有部署、自托管、自主可控

极目 Linux 桌面开支持根据实际环境选择使用和部署方式。

用户可以自主管理服务器连接信息、部署环境和扩展能力，减少对单一平台和固定服务模式的依赖。

## 适合谁？

极目 Linux 桌面适合：

- 管理多台 Linux 服务器的个人开发者；
- 希望像使用 Windows 一样操作 Linux 的用户；
- 需要统一 SSH 入口的个人工作室和小型团队；
- 希望通过可视化界面辅助命令行运维的技术人员；
- 希望使用 AI 分析日志、解释命令和处理服务器问题的用户；
- 不想在每台服务器上安装传统面板的用户；
- 暂时不需要部署重型堡垒机，但需要更清晰、更简单的服务器管理方式的团队。

无需安装完整桌面环境，通过 SSH 连接即可进入服务器桌面，使用文件、终端、浏览器、应用和 GMAI。

## 极目 Linux 桌面与传统服务器管理方式的区别

| 对比维度 | 传统 SSH / 命令行 | 传统服务器面板 | 极目 Linux 桌面                        |
|---|---|---|------------------------------------|
| 使用方式 | 通过终端输入命令操作 | 通过浏览器访问服务器面板 | 通过桌面客户端/私有部署网页端连接服务器               |
| 部署方式 | 无需在服务器安装额外面板 | 通常需要在服务器安装面板及相关服务 | 基于 SSH 连接，无需安装完整桌面环境               |
| 管理体验 | 灵活高效，但学习成本较高 | 可视化程度较高，但操作入口和功能结构相对固定 | 像使用 Windows 一样，通过文件、终端、浏览器和应用管理服务器 |
| 多服务器管理 | 需要手动维护连接配置并切换 | 通常以单台服务器管理为主 | 在一个客户端中统一添加、分组和切换多台服务器             |
| 服务器影响 | 资源占用低，不常驻额外服务 | 通常需要长期运行面板及相关组件 | 按需使用轻量组件，减少资源占用和环境侵入               |
| 安全与连接 | SSH 本身安全，但连接信息容易分散 | 通常需要开放 Web 面板端口和单独的登录入口 | 复用 SSH 连接和认证方式，无需额外开放管理面板端口        |
| 智能能力 | 依赖用户自行编写命令和脚本 | 主要依赖面板内置功能和插件 | 支持 GMAI、模型配置、Skills 和知识库，辅助完成服务器操作 |
| 应用与扩展 | 灵活，但安装和配置通常需要手动完成 | 应用生态较成熟，一键部署能力较强 | 提供应用中心和开放插件机制，生态持续扩展中              |
| 适合场景 | 熟悉 Linux 和命令行的用户 | 网站、数据库和运行环境的集中管理 | 个人开发者、小团队以及需要轻量多服务器管理的用户           |

## 核心能力

### 1. 服务器连接与组织

- SSH 原生连接
- 多服务器统一管理
- 主机分组、标签和搜索
- 开发、测试、生产等多环境组织
- 统一的服务器访问入口
- 连接配置本地安全保存
- 多台服务器批量命令执行

### 2. 桌面化服务器操作

- 无需安装完整桌面环境
- 文件管理与 SFTP 文件传输
- 多窗口终端
- 服务器浏览器
- 任务、进程和服务查看
- 服务器状态与资源监控
- 像使用 Windows 一样操作 Linux 服务器

### 3. GMAI 智能运维

- AI 对话与命令解释
- 命令补全和脚本生成
- 日志与配置分析
- 服务器故障排查
- AI 辅助执行服务器任务
- 自定义模型、Skills 和知识库

### 4. 应用与扩展

- 应用中心
- Docker 管理
- 网站、数据库和运行环境管理
- 常用服务器应用安装与配置
- 开放插件机制
- 支持用户开发和安装自定义插件
- GMSSH API 与第三方工具集成

### 5. 安全与部署

- 基于 SSH 隧道进行通信
- 无需额外开放管理面板端口
- 低侵入、低资源占用
- 按需启动轻量组件
- 凭证本地加密保存
- 开源、自托管和自主可控

## 产品路线图

极目 Linux 桌面正在从一个 SSH 服务器管理工具，逐步发展为 Linux 服务器的桌面化访问与工作平台。

未来将围绕以下方向持续演进：

- **更完善的主机组织**  
  支持多服务器分组、标签、环境区分和统一检索。

- **更完整的桌面化操作**  
  持续完善文件、终端、浏览器、服务、监控和应用管理能力。

- **更智能的运维体验**  
  增强 GMAI 在命令解释、日志分析、故障排查、脚本生成和任务执行方面的能力。

- **更开放的应用生态**  
  丰富应用中心、Docker 管理、插件机制、Skills 和 API 扩展能力。

- **更完善的团队协作**  
  逐步完善服务器共享、成员管理、权限控制和操作审计。

- **更灵活的自动化能力**  
  支持常用运维流程编排、批量操作和自定义自动化任务。

极目 Linux 桌面的长期目标是：

> **成为用户进入、管理和使用 Linux 服务器的统一桌面入口。**
